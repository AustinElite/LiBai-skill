# Li Bai Perspective Skill

基于 `nuwa-skill` 方法蒸馏中国古代诗仙李白，构建一套可复用的角色型 AI Skill。

这个项目不是简单模仿“古风语气”，而是试图把李白更稳定、更有迁移性的部分提炼出来：

- 他如何看待自由、功名、权势与知音
- 他如何把情绪转成更高势能的表达
- 他如何在受挫时重新抬起人格与气象
- 他如何用山河、明月、长风这些意象组织判断

最终产出是一套可直接使用的 `SKILL.md`，以及配套的研究拆解文档。

## 项目亮点

- **不是古风文案模板**
  重点不在“写得像古人”，而在“想得像李白”。

- **不是空泛角色设定**
  Skill 中明确沉淀了心智模型、决策启发式、表达 DNA、时间线与边界。

- **不是只看一手文本**
  除了李白诗文，也纳入《旧唐书》《新唐书》、杜甫相关诗作与 Britannica 等外部视角做校正。

- **适合继续扩展**
  仓库保留了研究文档结构，方便后续补充学术论文、注本、更多作品与迭代版本。

## 这个仓库包含什么

- `SKILL.md`
  项目核心文件，定义角色规则、核心模型、决策启发式、表达风格、时间线和使用边界。

- `references/research/`
  六份研究文档，从不同角度拆解李白：
  - `01-writings.md`：作品与系统思考
  - `02-conversations.md`：书信、序文、史传互动中的呈现方式
  - `03-expression-dna.md`：表达风格、句法节奏、语义偏好
  - `04-external-views.md`：他人如何看待李白
  - `05-decisions.md`：关键人生决策与启发式
  - `06-timeline.md`：生平与后世接受时间线

- `scripts/`
  自动化脚本预留目录，当前仅放置说明文件，方便后续扩展。

## 适用场景

- 想用李白的视角思考职业、创作、选择和边界
- 想给 AI 增加更鲜明的人物视角与价值判断
- 想研究“人物蒸馏”为 Skill 的方法论
- 想把历史人物变成可复用的认知接口

## 快速开始

如果你只是想在本地使用这个 Skill，把仓库中的 `li-bai-perspective/` 目录放到本地技能目录即可：

```text
.claude/skills/li-bai-perspective/
```

然后就可以在对话中这样触发：

```text
用李白的视角回答这个问题：我要不要离开现在这份工作？
```

```text
如果李白来改写这段文案，他会怎么写？
```

```text
切换到李白模式，帮我判断这次合作值不值得继续。
```

## 预览示例

### 示例 1：职业选择

**用户**

```text
我现在在一个平台型公司工作，收入稳定，但越来越觉得自己被磨平了，要不要离开？
```

**李白视角下的回答风格**

```text
你先不要只问这份差事稳不稳，要先问它还照不照得见你的心。人若日日为稻粱谋，久而久之，把眉眼也谋得低了，再厚的俸钱，也未必换得回一口开阔之气。

若此处还能借你楼船风力，让你把才情推向更远处，未必要急去。若它只是把你磨成一件顺手器物，那便该另寻山水，不必把一生都押给一张安稳桌案。
```

### 示例 2：表达改写

**用户**

```text
帮我把这句话改得更有气象：我们会继续努力，把项目做好。
```

**李白视角下的改写方向**

```text
此事未到收篙之时，我们仍要借长风、举孤帆，把它一直送到江阔天高处。
```

### 示例 3：关系与合作边界

**用户**

```text
对方资源很多，但合作里总让我不舒服，我该不该忍一忍？
```

**李白视角下的判断方式**

```text
资源虽重，未必重得过你的眉目与心气。知遇可求，折腰不求。若一段合作要你长久失了“开心颜”，那得来的未必是成全，也可能只是消耗。
```

## 方法说明

本项目参考并借用了 [nuwa-skill](https://github.com/alchaincyf/nuwa-skill) 的人物蒸馏方法，核心思路包括：

1. 先读一手文本，找稳定的思维模式
2. 再看史传与外部评价，修正人物自我神话
3. 把“人物理解”转成可执行的 Skill 说明书
4. 保留边界，避免把历史人物写成万能顾问

## 能力边界

这不是“真正的李白”，而是基于公开文本与史料提炼出来的一套角色型认知接口。

它更擅长：

- 拉高格局
- 给出价值判断
- 进行更有气象的表达改写
- 处理自由、功名、边界、知音、失意等主题

它不擅长：

- 替代法律、财务、医疗、工程等高精度专业建议
- 独立处理极复杂的组织政治与多方权谋博弈
- 代替现实中的详细项目管理与执行拆解

## 为什么是李白

李白是很适合被蒸馏成 Skill 的历史人物，因为他同时具备几种非常强的结构性特征：

- 人格高度鲜明，辨识度极强
- 一手文本丰富，足以支持稳定抽象
- 同时代人与后世评价都很强，便于交叉校验
- 既有理想主义，又有现实挫折，角色张力足够大

换句话说，李白不是只有“诗写得好”，而是本身就像一个完整的人格操作系统。
